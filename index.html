Finance

Finance is a private, self-hosted app that one person uses to keep track of their own grocery spending. It is not offered to the public and has no sign-up.

What it does

  • Reads emailed till slips (PDF receipts) from the owner's own Gmail, using a label the owner set up, and turns them into line items.
  • Lets the owner mark which items were shared with a housemate.
  • Writes one summary row per receipt into a Google Sheet the owner shares with that housemate.

Google data it uses

  • gmail.readonly: to find and download receipt attachments. It never sends, changes or deletes email.
  • spreadsheets: to add rows to the owner's grocery sheet.

See the privacy policy.
